# Changelog

## 1.0.0 — 2026-10-11

First public release.

- One portable skill (`skills/compound-gtm/`) with a front door and 24 moves across home, market, message, motion, pressure-test and learn.
- GTM home contract: `ICP.md`, `POSITIONING.md`, `PROOF.md`, `PLAYS.md`, `VOICE.md`, `COMPANY.md`, `motions/`.
- Evidence levels (Observed, Heard, Reported, Believed), proof permission tags (public, anonymised, internal) and play statuses (testing, working, proven, retired).
- `create_home.py` to scaffold a home or a motion folder without overwriting.
- Generated `/cg-*` commands for Claude Code and a zip for claude.ai upload.
- Review route: lenses chosen by asset, merged into one verdict, claim check and fixed version.
- Counting, counter-signal, permission and date-format rules for evidence tags.
- Worked example: a fictional vendor's home after three motions, with every count traceable to its motion's results.
- Home `README.md` template, so teammates opening the folder know how to read a line.
- `scripts/build.py --check` validates frontmatter limits, routing coverage, move counts, manifest versions, links and generated files; CI runs it with a `create_home.py` smoke test.
- Deterministic skill zip: an unchanged skill rebuilds to an identical archive.
- README visuals in the Revenue Puzzles style, light and dark, generated by `scripts/render_assets.py` from the example's own numbers; social preview image.
